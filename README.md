¡Bienvenido a este repositorio! Este espacio contiene el material académico desarrollado por Ian Isaza Bermúdez, enfocado en la resolución de ecuaciones mediante código y en la presentación de conceptos clave de programación.

📋 Contenido del Repositorio
El repositorio está organizado en dos componentes principales:

Código de Ecuaciones: Implementación lógica para resolver sistemas de ecuaciones o cálculos matemáticos específicos.

Presentación de Fundamentos: Material educativo y explicativo sobre el manejo de variables y condicionales en el lenguaje Java.

🛠️ Tecnologías Utilizadas
Lenguaje principal: Java (JDK 17 o superior recomendado)

Entorno de Desarrollo (IDE): Visual Studio Code / Eclipse / IntelliJ IDEA

Control de Versiones: Git y GitHub

A continuación se detalla la organización de los archivos dentro del repositorio::

Plaintext

📖 Conceptos Cubiertos en la Presentación
La presentación incluida en este repositorio aborda los pilares esenciales para comenzar a programar en Java:

1. Variables en Java
Explicación de cómo almacenar datos en memoria utilizando los tipos de datos adecuados:

Primitivos: int, double, boolean, char.

De referencia: String.

2. Estructuras Condicionales
Uso de la lógica booleana para la toma de decisiones en el flujo del programa:

Estructuras simples y compuestas: if / else if / else.

Estructura de selección múltiple: switch.

💻 Cómo Ejecutar el Código
Para correr el código de ecuaciones localmente, asegúrate de tener instalado el Java Development Kit (JDK) y sigue estos pasos:

Clonar el repositorio:

Bash
git clone https://github.com/ianisaza/tu-repositorio.git
Navegar al directorio del proyecto:

Bash
cd tu-repositorio/src
Compilar el archivo Java:

Bash
javac Ecuaciones.java
Ejecutar el programa:

Bash
java Ecuaciones
